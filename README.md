Task 6 - Amazon Prime KNN Classification

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/poojareddylankala13/Task-6-AmazonPrime-KNN-Classification/blob/main/Task6-AmazonPrime.ipynb)

Objective
To build a classification model using the K-Nearest Neighbors (KNN) algorithm on the Amazon Prime dataset and evaluate its performance.

Tools Used
- Google Colab
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

Steps Performed
1. Imported the Amazon Prime dataset
2. Explored the dataset using head(), info(), and describe()
3. Handled missing values
4. Selected relevant features for classification
5. Encoded categorical labels using Label Encoder
6. Normalized features using StandardScaler
7. Split data into training and testing sets
8. Trained KNN Classification model
9. Made predictions on test data
10. Evaluated model using accuracy score
11. Generated confusion matrix and classification report
12. Experimented with different K values
13. Identified the best K value
14. Visualized K vs Accuracy graph
15. Visualized KNN decision boundary

Dataset 
Amazon Prime Movies and TV Shows Dataset from Kaggle
